# Program Konversi Suhu dalam Bahasa C

## Deskripsi
Program konversi suhu berbasis bahasa C yang memungkinkan pengguna mengonversi nilai suhu dari Celsius, Fahrenheit, Reamur, dan Kelvin. Program menggunakan fungsi dan struktur kontrol `switch-case` untuk memproses pilihan pengguna.

## Fitur
- Konversi Celsius ke Fahrenheit, Reamur, dan Kelvin.
- Konversi Fahrenheit ke Celsius, Reamur, dan Kelvin.
- Konversi Reamur ke Celsius, Fahrenheit, dan Kelvin.
- Konversi Kelvin ke Celsius, Fahrenheit, dan Reamur.
- Menu interaktif untuk memilih jenis konversi.
- Opsi untuk mengulangi konversi tanpa menjalankan ulang program.

## Struktur File
- `konversisuhufun.c`: file program utama.
- `funsuhu.c`: file yang berisi fungsi-fungsi konversi suhu.

## Persyaratan
- Compiler bahasa C, seperti GCC.
- Terminal atau editor kode, seperti Visual Studio Code.

## Cara Menjalankan

1. Pastikan kedua file C berada di folder yang sama.
2. Buka terminal pada folder proyek.
3. Kompilasi program menggunakan GCC:

```bash
gcc konversisuhufun.c -o konversi_suhu
```

4. Jalankan program.

Windows:

```bash
konversi_suhu.exe
```

Linux atau macOS:

```bash
./konversi_suhu
```

## Cara Menggunakan
1. Pilih satuan suhu awal.
2. Pilih satuan suhu tujuan.
3. Masukkan nilai suhu yang ingin dikonversi.
4. Lihat hasil konversi.
5. Masukkan `y` jika ingin mengulang atau `n` untuk mengakhiri program.

## Tujuan Proyek
Proyek latihan untuk mempelajari dasar-dasar bahasa C, meliputi fungsi, variabel, input-output, `switch-case`, dan perulangan.
